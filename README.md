# 雲間 (Kumoma)

青空文庫への入口 — 「15分で読める、口語の短編」を探せるプロトタイプ。

## 公開方法

このフォルダの中身を GitHub リポジトリの直下（ルート）に置き、
GitHub Pages を有効化すれば `index.html` がそのまま公開されます。

- `index.html` … 単体で完結するプロトタイプ本体（データはこのファイルに埋め込み済み）
- `data/index.json` / `data/authors.json` … Phase 1 で生成した元データ（参照用。サイト表示には不要）

詳しい手順は Claude とのチャット履歴を参照。
